🚀 DegenChat Widget Embed

Add this DegenChat widget to any website with just a few lines of code!

📋 Instructions:
  1. Copy the code below
  2. Paste it anywhere in your HTML page (preferably before closing </body> tag)
  3. That's it! The chat widget will appear as a floating button

📝 Embed Code:

<!-- DegenChat Widget --> <div id="chat-widget-button" class="chat-button" onclick="toggleChat()"> <span class="chat-icon">💬</span> <div class="notification-badge hidden">1</div> </div> <div id="chat-widget" class="chat-widget hidden"> <iframe src="https://chat.gamescampus.co.kr/widget.html" width="100%" height="100%" frameborder="0" allow="clipboard-write"> </iframe> </div> <style> .chat-button { position: fixed; bottom: 20px; right: 20px; width: 60px; height: 60px; background: linear-gradient(135deg, #6366f1, #8b5cf6); border-radius: 50%; display: flex; align-items: center; justify-content: center; cursor: pointer; z-index: 1001; transition: all 0.3s ease; box-shadow: 0 10px 25px rgba(99, 102, 241, 0.3); } .chat-button:hover { transform: translateY(-3px); box-shadow: 0 15px 35px rgba(99, 102, 241, 0.4); } .chat-icon { font-size: 1.5rem; } .notification-badge { position: absolute; top: -5px; right: -5px; background: #ef4444; color: white; border-radius: 50%; width: 20px; height: 20px; display: flex; align-items: center; justify-content: center; font-size: 0.75rem; font-weight: 600; } .notification-badge.hidden { display: none; } .chat-widget { position: fixed; bottom: 100px; right: 20px; width: 420px; height: 600px; background: #1e293b; border-radius: 12px; border: 1px solid rgba(255, 255, 255, 0.1); box-shadow: 0 25px 50px rgba(0, 0, 0, 0.3); z-index: 1000; transition: all 0.3s ease; overflow: hidden; } .chat-widget.hidden { opacity: 0; transform: translateY(20px) scale(0.95); pointer-events: none; } </style> <script> let chatVisible = false; function toggleChat() { const chatWidget = document.getElementById('chat-widget'); const chatButton = document.getElementById('chat-widget-button'); const badge = document.querySelector('.notification-badge'); chatVisible = !chatVisible; if (chatVisible) { chatWidget.classList.remove('hidden'); badge.classList.add('hidden'); } else { chatWidget.classList.add('hidden'); } } // Close chat when clicking outside document.addEventListener('click', function(e) { const chatWidget = document.getElementById('chat-widget'); const chatButton = document.getElementById('chat-widget-button'); if (chatVisible && !chatWidget.contains(e.target) && !chatButton.contains(e.target)) { toggleChat(); } }); </script> <!-- End DegenChat Widget -->
🎨 Customization Options:
  • Change Colors: Modify the background: linear-gradient(135deg, #6366f1, #8b5cf6); line
  • Different Position: Change bottom: 20px; right: 20px; to bottom: 20px; left: 20px;
  • Different Size: Adjust width: 420px; height: 600px;
  • Custom Icon: Replace the 💬 emoji with any other emoji or text

🔧 Troubleshooting:

  • If the widget doesn't appear, check browser console for errors
  • Make sure the domain chat.gamescampus.co.kr is accessible
  • Test in an incognito window to rule out browser extensions
  • Ensure JavaScript is enabled in the browser
